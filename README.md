## ✨ À propos

**YouCode Events** est une plateforme web qui centralise les événements organisés par YouCode. Le projet consiste à concevoir une interface **moderne**, **responsive** et **accessible**, permettant aux visiteurs de découvrir les événements et de s'y inscrire facilement.

## 🧭 Pages du site

| Page | Description |
|------|-------------|
| 🏠 **Accueil** | Header avec navigation, section Hero avec boutons d'action, aperçu des prochains événements |
| 📅 **Événements** | Liste des événements avec leurs informations principales |
| 🔎 **Détail d'un événement** | Programme, intervenants et informations pratiques |
| 🎤 **Intervenants & partenaires** | Présentation des intervenants et des partenaires |
| 📝 **Inscription** | Formulaire d'inscription à un événement |

## 🎨 Design et maquette

La maquette est réalisée avec **Figma** et repose sur un **Design System** cohérent : couleurs, typographies, espacements et composants réutilisables.

| Couleur | Usage |
|---------|-------|
| 🟠 Orange | Couleur principale, boutons d'action |
| 🟤 Beige | Arrière-plans et sections |
| ⚪ Blanc | Surfaces et cartes |
| 🟢 Vert turquoise | Accents et éléments secondaires |

## 📱 Responsive et accessibilité

Le site suit une approche **Mobile First** : les Media Queries adaptent la navigation, les cartes et la mise en page aux mobiles, tablettes et ordinateurs.

- ♿ **Sémantique HTML** : balises `header`, `nav`, `main`, `section`, `footer`
- 🌗 **Contrastes** suffisants entre texte et arrière-plan
- 🏷️ **Labels** associés à tous les champs de formulaire
- ⌨️ **Navigation au clavier** possible sur l'ensemble du site

## 🚀 Installation

**1. Cloner le dépôt**

```bash
git clone https://github.com/yassinedzaouha/YouCode_Events.git
```

**2. Accéder au dossier du projet**

```bash
cd YouCode_Events
```

**3. Lancer le site**

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension **Live Server** de Visual Studio Code.

## 👥 Workflow d'équipe

Le projet est développé en équipe sur un dépôt GitHub commun, avec le workflow **Git Flow** :

- 🌳 `main` : version stable
- 🌱 `develop` : branche d'intégration
- ✨ `feature/*` : une branche par fonctionnalité
- 🔀 **Pull Requests** : chaque fonctionnalité est fusionnée après revue de code

Les revues de code permettent de partager les connaissances et d'améliorer la qualité du code.
